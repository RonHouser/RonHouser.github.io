# Ron Houser | Portfolio

**Live site:** [ronhouser.github.io](https://ronhouser.github.io)

Personal portfolio of Ron Houser, Senior Business Intelligence Analyst and former USMC officer.
I design enterprise Power BI and Snowflake solutions: executive scorecards, KPI reporting,
and self-service analytics for S&OP, demand planning, and manufacturing scheduling.

## About this site

The site is built like one of my own dashboards:

- **Impact scorecard:** career results as animated KPIs
- **Case files:** three projects, each with an interactive visual
- **Skills as a star schema:** dimension tables that cross-filter my experience, like a Power BI slicer
- **Career Gantt chart:** my path charted as a project timeline
- **Command menu:** press `Ctrl K` (or `⌘ K`) to jump anywhere on the page

## Built with

- A single hand-written HTML file: HTML, CSS, and vanilla JavaScript, with no frameworks or build step
- Light and dark themes, responsive layout, keyboard navigation, and reduced-motion support
- Hosted on GitHub Pages
